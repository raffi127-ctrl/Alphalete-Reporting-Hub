Fill Apex

Drag it up to the bookmarks bar. Don’t click it here — it only does something on an Apex page.

  1. Drag the button above onto the bookmarks bar.
  2. In Apex, go to Roster → Employees → Pending.
  3. Press Get this week’s setup on the Hub, then click the bookmark. Chrome asks to read the clipboard the first time — allow it. That’s how it gets the week.

Don’t retype or email the code. macOS turns straight quotes into curly ones, which breaks it silently — the button then does nothing at all when clicked. Drag it, or use Copy below.
