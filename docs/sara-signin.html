Clear the SaraPlus code check

Takes about a minute. You will need your usual SaraPlus password, and the inbox that receives SaraPlus's emailed code.

1
Do this on the office computer that runs LucyECO — the one you set up. Signing in on your phone, or in your own browser, will not reach her.
2
Open Terminal: hold Command and tap Space, type terminal, press Return.
3
Press the button, then paste into that window and press Return.
loading…
4
Your SaraPlus password is not being changed and does not need to be. Use the one you already sign in with.
5
A browser window opens on SaraPlus. Sign in there, then enter the code SaraPlus emails you. It closes by itself, then spends about a minute checking that the automatic reads can get in too. Wait for the last line: ALL SET means you're done; NOT YET means send the reporting team a photo of the window.
This is not a password problem. SaraPlus accepted the password and is checking the browser — it does that when it sees a new computer. Changing the password does not clear it, and the code has to be typed into the window this opens: signing in with your own browser, or on your phone, does not reach Lucy.
