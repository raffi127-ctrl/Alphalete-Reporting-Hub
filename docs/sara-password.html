Enter your new SaraPlus password

Takes about a minute. You will need the SaraPlus password you sign in with today.

1
Do this on the office computer that runs LucyECO — the one you set up. Lucy signs in from that computer with a password saved there; when the SaraPlus password changes, that saved copy has to change too.
2
Open Terminal: hold Command and tap Space, type terminal, press Return.
3
Press the button, then paste into that window and press Return.
loading…
4
A box pops up asking for the SaraPlus email, then the password. Type the password you use now. It then signs in by itself to check. If it asks for the code SaraPlus emails, enter it in the window that opens.
5
Wait for the last line. "That worked" means you're done — alerts start again within a few minutes. Anything else: send the reporting team a photo of the window.
Nothing else changes. Your OwnerVille login, your channels and your schedule are all left alone. Only the SaraPlus password Lucy uses is replaced.
