# Streamlit Community Cloud deps for the COMBINED site (entry: streamlit_app.py).
#
# THIS FILE IS A SUPERSET OF EVERY APP'S OWN requirements.txt, ON PURPOSE, and
# it must stay one.
#
# Seven tools in this repo are ALSO deployed as their own Community Cloud apps
# and owners hold links to them. Cloud resolves dependencies from a file next
# to the entry script or from the repo root, and which one wins is not worth
# betting seven working tools on: if root ever wins, an app whose dependency is
# missing here loses it on its next rebuild. document_builder would stop making
# PDFs (reportlab, PyMuPDF) and four tools would lose drag-and-drop ordering
# (streamlit-sortables) -- all from a file that looks like it only concerns the
# combined site.
#
# So: adding a tool to streamlit_app.py means adding its dependencies here,
# and removing one never means removing a line unless no tool needs it.
